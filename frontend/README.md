## Overview

**Style-A-Silhouette** is an AI-assisted web application that analyzes a user's outfit using camera input and generates styling suggestions.

The system captures an image using the browser camera, sends it to the backend for processing, and returns intelligent recommendations based on detected clothing elements.

This project demonstrates the integration of:

• Camera APIs
• Image processing pipelines
• Backend REST APIs
• AI-driven suggestion logic
• Modern MERN-stack architecture

## Installation

Clone the repository

```
git clone https://github.com/DebugMajor/style-silhouette.git
cd style-silhouette
```

Backend setup

```
cd backend
npm install
npm run dev
```

Frontend setup

```
cd frontend
npm install
npm run dev
```
